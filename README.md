# Previsão do Tempo

Uma aplicação web para consultar a previsão do tempo de uma cidade informada pelo usuário.

## Como acessar

- Copie o link (URL) do arquivo HTML.
- Acesse o [HTML Preview](https://htmlpreview.github.io/).
- Cole o link no campo indicado e clique em Preview.

## Como usar

- Escreva o nome da cidade em português ou inglês
- Clique em **Pesquisar** para consultar as informações meteorológicas

## Tecnologias e serviços utilizados
- HTML/CSS
- JavaScript
- [OpenMeteo](https://open-meteo.com/)
